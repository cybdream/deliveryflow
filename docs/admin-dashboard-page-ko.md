# 관리자 배송 현황 화면

관리자 계정으로 로그인해 기준일 전후 3일을 포함한 7일간의 배송 상태를 확인하는 간단한 운영 화면입니다.

- 주소: `/admin.html`
- 로컬: `http://localhost:8080/admin.html`
- Railway: `https://deliveryflow-production.up.railway.app/admin.html`

## 기능

1. 관리자 이메일과 비밀번호로 로그인합니다.
2. 기본값인 오늘 또는 선택한 기준일을 중심으로 전 3일·후 3일의 현황을 함께 조회합니다.
3. 7일 전체 배송 건수, 완료 건수, 진행 중 건수를 요약 카드로 봅니다.
4. 7일 상태별 합계와 날짜별 상태별 건수를 표로 확인합니다.
5. 전체·완료·진행 중 또는 상태별 카운터를 누르면 같은 7일 범위의 배송 상세 목록을 확인합니다.
6. 로그아웃하면 브라우저 탭에 보관한 로그인 토큰을 즉시 삭제합니다.

## 보안 방식

화면 자체는 로그인 페이지를 보여 주기 위해 공개 경로지만, 실제 현황 데이터는 관리자 전용 API인 `GET /api/v1/dashboard/delivery-status`에서 가져옵니다. 로그인으로 받은 JWT는 `sessionStorage`에만 보관하므로 해당 브라우저 탭을 닫으면 자동으로 사라집니다. 비밀번호는 저장하지 않습니다.

## 테스트

1. `admin.html`을 엽니다.
2. 로컬 환경의 관리자 계정으로 로그인합니다.
3. 기준일을 바꾸거나 **현황 새로고침**을 눌러 전후 3일을 포함한 7개 행과 합계가 표시되는지 확인합니다.
4. 상태별 카운터를 눌러 주문번호, 배송 추적번호, 기사, 상태가 포함된 상세 목록이 표시되는지 확인합니다.
5. **로그아웃** 후 새로고침하면 다시 로그인 화면이 보이는지 확인합니다.
